\begin{itemize}
  \item \textbf{Conceptualization:} formulating the research questions and the overall
        experimental design.
  \item \textbf{Data curation:} constructing the obfuscated dataset from methods2test,
        filtering malformed entries, and producing the JSONL training/evaluation splits.
  \item \textbf{Investigation:} running fine-tuning experiments across six checkpoints

        the retry mechanism, and the CodeReader judge ensemble configuration.
  \item \textbf{Software:} implementing the renaming pipeline, the CodeReader grading tool
        (published on PyPI), and all evaluation scripts.
  \item \textbf{Writing -- original draft:} writing all sections of the paper and thesis.
  \item \textbf{Writing -- review \& editing:} incorporating feedback from supervisors.
\end{itemize}
